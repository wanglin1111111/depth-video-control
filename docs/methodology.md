# 深度驱动 AI 视频控制：方法论全文

> 源内容提炼自「实拍视频 → 抽深度图 → 约束 AI 生成」一线实践。
> 本文是 `depth-video-control` 技能的方法论底座；可执行工作流见 `../SKILL.md`。

## 一、奥卡姆剃刀：剥掉包装后的真实主题

剃掉"GPT-6""邪修""节点""2.5M"这些包装词，剩下不可再删的最小事实是：

**一段实拍视频 → 抽成深度图 → 拿它当骨架去约束 AI 生成。**

用一句话说穿：**AI 视频的控制权，正从"文字提示词"前移到"真实空间结构"。**

过去你用语言描述画面（抽卡、碰运气）；现在你直接给 AI 一段空间骨架（深度图），它照着骨架长肉。

再剃第二刀，去掉"深度图"这个技术词，本质是：**别让 AI 猜空间，把空间直接喂给它。**

## 二、核心提炼：四种玩法

### ① 深度图控制 · 复杂站位

实拍一段多人/多物场景，抽深度图连进生成节点，人物前后、遮挡、远近关系一次复刻——不用再靠提示词反复描述"谁在前谁在后"。

### ② 深度视频驱动 · 运镜复刻

手持抖动、推拉摇移这些"不稳定镜头"，提示词永远写不准，但实拍视频的深度序列天然带这些运动信息，直接还原，镜头语言的"人味"回来了。

### ③ 分层创作 · 分镜脚本简化

既然空间与运动已由深度视频托底，提示词就不必再管构图，只管风格、材质、光线。创作者从"描述画面"退回到"规划镜头"，精力回到分镜本身。

### ④ 底层逻辑 · 算力替代

理解"AI 的首要任务是还原画面"这一底层逻辑，就能用低成本的结构输入，替代高算力模型的空间推理——这是应对算力成本过高的现实解法。

## 三、现实行动指南：怎么塞进你的工作流

### 第一步：改素材准备方式（成本最低、收益最大）

别再从空白提示词起步。先想清楚这个镜头"现实中怎么拍"，然后用手机真的拍一遍——哪怕只是你拿着手机走位、比划动作、找人站个位。拍得糙没关系，深度图只吃结构不吃画质。

### 第二步：把实拍转成深度序列

用深度估计工具（Depth 类模型 / ControlNet Depth / 平台内置的深度控制节点）导出灰度深度视频。这一步是从"实拍素材"到"AI 控制信号"的关键转换，也是整套方法的枢纽。

### 第三步：提示词降级，只写它该写的

深度视频接管了构图、站位、运镜；你的提示词只保留三件事：**主体特征、材质风格、光线氛围**。提示词越短越稳，抽卡次数会明显下降。

### 第四步：迭代对象从"改词"变成"改拍"

生成不对时，过去是反复调提示词；现在的修正动作是——**回去重拍一遍站位或运镜**。这是工作流里最大的心智转变：调试对象从语言层下沉到了物理层。

### 第五步：按镜头类型分工

- 复杂空间关系、多人站位、人物动作复刻 → 优先走**深度视频路线**
- 纯氛围、抽象、无实拍可能性的画面 → 仍走**文生视频抽卡**

两条线并行，别把所有镜头都套进同一套流程。

### 落地提醒

深度方案的上限由实拍质量决定。遮挡严重、玻璃/透明/反光物体、快速运动模糊的场景，深度估计容易崩，这类镜头要提前识别出来，别硬上。

## 四、与提示词工程流派的分工

| 维度 | 抽卡流派（纯提示词） | 深度流派（本技能） |
|---|---|---|
| 空间由谁决定 | 文字描述 + 模型脑补 | 实拍深度骨架 |
| 提示词职责 | 构图+站位+运镜+风格全写 | 仅三要素：主体/材质/光线 |
| 抽卡率 | 高（空间靠运气） | 低（空间已托底） |
| 调试动作 | 改词 | 改拍 |
| 适用镜头 | 抽象/氛围/无实拍可能 | 复杂站位/运镜复刻/动作复刻 |
| 成本模型 | 高算力空间推理，反复生成烧卡 | 一次实拍 + 一次估计，结构输入替代推理 |

两套工具可以叠加：深度路线出的镜头，提示词仍按三要素规则写，需要跨镜一致性时再进分镜表流程（见姊妹技能 `ai-video-prompt-studio`）。

## 五、心智转变清单

1. **素材先于提示词**：先拍后写，不是先写后抽。
2. **结构对 > 画质好**：手机糙拍合格，站位错了全错。
3. **提示词是调味料不是骨架**：骨架是深度，提示词只管质感与氛围。
4. **重拍是正常迭代**：连续 2 次不满意就回去拍，别在语言层打第 3 轮。
5. **崩点提前识别**：四类崩点（遮挡/透明/反光/运动模糊）一票改路由，不恋战。
