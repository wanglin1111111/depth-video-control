# 提示词降级：三要素模板

深度接管了构图/站位/运镜后，提示词只写三件事：**主体特征、材质风格、光线氛围**。

## 模板

```
[主体特征]  是谁/什么：数量、外貌、服装、动作（动作可省，深度已带）
[材质风格]  什么质感：写实/皮克斯/水墨/赛璐璐；材质细节（皮肤/织物/金属）
[光线氛围]  什么光：顺光/逆光/烛光/霓虹；色温；情绪基调
```

长度基准：**1-3 句**。超过 3 句说明你在重新描述空间——删掉。

## 降级前后对照

**降级前（抽卡流派，空间靠嘴说）**：
> 电影感镜头，画面左侧前景站着一个穿红裙的女人，她身后三米处站着一个男人，男人侧身半遮挡，背景是雨夜的东京街头，镜头从右往左缓慢横移，手持轻微晃动……

**降级后（深度托底，只写三要素）**：
> 红裙女人，湿发贴脸，表情冷淡；写实电影质感，雨水反光的皮肤与绸缎裙面；雨夜霓虹，青橙对比色，情绪疏离。

构图（谁前谁后）、运镜（横移+手持）全部由深度序列提供，一个字都不用写。

## 禁写清单（写了=与深度打架，validate.py 拦截）

| 类别 | 例词 |
|---|---|
| 构图/站位 | 前景/背景/左右/遮挡/站在一起/构图/景别（特写/远景） |
| 运镜 | 横移/推拉摇移/手持/跟拍/镜头运动/camera movement |
| 空间关系 | 距离/三米处/谁在谁后面/透视 |

例外：提示词里的动作描写（转身、挥手）可以保留——深度带轨迹，动作语义仍需文字补充。

## 迭代规则（硬规则的执行细节）

- 第 1 次生成不满意 → 允许微调三要素措辞（1 次）
- 第 2 次仍不满意 → **停止改词，回实拍**：重拍站位或运镜
- 判据：不满意点若是"位置/遮挡/运动"类 → 100% 回实拍；若是"质感/光线/情绪"类 → 留在三要素内修
