# 镜头路由决策表

逐镜头判断走哪条线。两条线并行，**别把所有镜头都套进同一套流程**。

## 深度路线（走深度视频）

满足任一条即走深度路线：

| 判据 | 典型场景 |
|---|---|
| 复杂空间关系：人物/物体前后、遮挡、远近关系需要精确复刻 | 多人对话、人群穿行、前景遮挡后景 |
| 多人站位需要一次成型 | 会议、群戏、合影、走位调度 |
| 人物动作复刻：需要还原特定走位或肢体动作 | 舞蹈走位、体育动作、表演调度 |
| 运镜需要"人味"：手持、推拉摇移、不稳定镜头 | vlog 感、纪实感、手持跟拍 |
| 提示词反复写不准同一个镜头（抽卡率高） | 写"左边站着一个人后面是树"仍出不来 |

## 抽卡路线（文生视频/图生视频，纯提示词）

满足任一条即走抽卡路线，**不要拍深度素材**：

| 判据 | 典型场景 |
|---|---|
| 纯氛围/抽象画面，现实中拍不出来 | 星云、粒子、水墨流动、概念空间 |
| 无实拍可能性：超现实尺度、非物理场景 | 城市在天空漂浮、巨兽穿行云间 |
| 单主体静态画面，构图一句话能说清 | 产品特写（无复杂遮挡）、空镜 |

## 边界判例

| 情况 | 判定 |
|---|---|
| 单人物简单走位 + 简单背景 | 看需求：构图要求高→深度；氛围优先→抽卡 |
| 玻璃/水面/反光主体但空间关系复杂 | 先按 gotchas 处理崩点（打柔光/降速度/局部遮罩），处理后走深度，处理不了改抽卡 |
| 实拍只有 3 秒且运镜简单 | 深度序列太短约束力不足，改抽卡 + 首尾帧 |
| 同一场景多个镜头 | 实拍一次，多镜头复用同一段深度序列的不同区间 |
